# Controls / 操作方法

Two layouts are available in SETTINGS > CONTROLS > Control Layout. The default follows Scooter Flow's twin
stick scheme. Glyphs in the game follow the controller in use (Xbox, PlayStation, Nintendo) or the keyboard.
Every action can be rebound (confirm on a row, then press a button, trigger or key); each layout keeps its own
bindings (`<user folder>/input_flow.json`, `input_classic.json`). Defaults: `config/input.json`,
`config/input_classic.json`.

設定 > 操作 > 操作タイプ で 2 種類から選べます。既定は Scooter Flow 式のツインスティックです。ボタン表示は
使用中のコントローラー（Xbox / PlayStation / Nintendo）やキーボードに合わせて自動で切り替わります。
すべての操作は割り当て変更できます。

## Scooter Flow style (default) / Scooter Flow 式（既定）

| input | on the ground | in the air |
|---|---|---|
| Left stick | carve / lean; back = manual, forward = nose manual | small body lean |
| Right stick down (hold) | compress: charges the pop, pumps through transitions | spin / flip |
| Right stick up (flick) | pop (stronger after compressing) | spin / flip |
| Right stick left / right | - | spin |
| A | push | - |
| B | brake | - |
| RT + right stick | - | scooter tricks (push the stick all the way) |
| LT + right stick | - | grabs (held while the trigger is held) |
| LB / RB | - | spin left / right |
| X | revert (180 on the ground) | - |
| Y | camera: third person / close / far / first person | camera |
| RS click | camera reset | camera reset |
| D-pad up / D-pad down, View | set checkpoint / respawn | |
| Menu (Start) | pause | pause |

Scooter tricks (hold RT):

| right stick | trick |
|---|---|
| right | Tailwhip (right again during it = double, triple) |
| left | Heelwhip |
| right, then left | Whip rewind (heel rewind: left, then right) |
| up | Barspin (up again = double) |
| down | Fingerwhip |
| up-right / up-left / down-right | Scooter flip / Bri flip / Kickless |

Grabs (hold LT): up = no hander, left = one hand, right = can can, down = no footer, diagonals = deck grab.
Spins and flips are free: rotate with the right stick (or LB / RB) and land straight; a backflip with a 180
becomes a flair.

Keyboard: WASD = left stick, arrow keys = right stick, Space = pop (hold to compress), Left Shift = push,
Left Ctrl = brake, F = trick (RT), G = grab (LT), Q / E = spin, V = revert, Tab = camera, C = checkpoint,
R = respawn, Esc = pause.

## Classic layout / クラシック

| input | action |
|---|---|
| Left stick | carve; in the air spin (x) and flip (y); back / forward = manual / nose manual |
| A (hold / release) | compress / pop |
| X | push |
| B or LT | brake |
| Right stick flick (air) | left / right tailwhip, down heelwhip, up barspin, diagonals flips, left then right rewind |
| RT + right stick | grabs |
| LB / RB | spin |
| Y | revert |

## Menus / メニュー

Left stick or D-pad to move, A to select, B to go back, LB / RB to switch tabs or shop categories, X to save
the scooter setup, right stick or mouse drag to rotate the shop camera, triggers or the mouse wheel to zoom.
