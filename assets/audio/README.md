# Sound effects

All files in this folder are generated by `scoot_assetgen --audio` (tools/assetgen/audio_gen.cpp):
original procedural synthesis, no recordings or third party samples. They are released with the game
under the same terms as the rest of the project.

Any file can be replaced with a recording of the same name (WAV, MP3 or FLAC; mono is best for 3D
sounds). Loops (`roll_*`, `grind_*`, `wind`, `ambience_*`) should loop seamlessly. The rolling loops
are pitched and faded by speed at runtime, so record them at a medium riding speed.
